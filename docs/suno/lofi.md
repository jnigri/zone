# Suno prompts: Lofi

28 songs, 4 per mood. Paste one block into Suno's song description box and switch **Instrumental** on.
Every prompt is under 1000 characters. After downloading, name the file `mood.genre.title`, using the prefix
shown under each heading, e.g. `cruise.lofi.autocomplete.m4a`, so Zone files it under the right mood and genre.

Direction: soulful jazz-hop at heart, with sampled piano loops, flute and sax, upright bass and drums that
really swing. The energetic moods borrow from French house, gritty electro and turntablism.
